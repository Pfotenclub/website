# Pfotenclub Website

This is the source code for the Pfotenclub website, built using [Astro](https://astro.build/). The website is designed to provide information about the Pfotenclub.

## 🚀 Getting Started

This is just the source code for the website. To view the website, you can visit [pfotenclub.eu](https://pfotenclub.eu).
Want to run the website locally? Follow these steps:

1. Don't.
2. Just don't.
3. Seriously, it's not worth it. The website is already live and you can view it online. If you want to contribute or make changes, please fork the repository and submit a pull request.

## 🤝 Contributing

If you want to contribute to the website, please fork the repository and submit a pull request. We welcome contributions of all kinds, including bug fixes, new features, and improvements to the design.
Please make sure to follow the existing code style and include tests for any new features or bug fixes.
Any contributions that do not follow the code style or do not include tests may be rejected. @DiniskaWolfiii is the main maintainer of the project and will review all pull requests.
